추천 시스템과 지식 그래프 기반 질의응답을 연구합니다. 데이터의 관계를 그래프로 표현하고 사용자의 맥락을 반영해 필요한 정보를 더 잘 찾는 방법에 관심이 있습니다. 이미지에서 얻은 지식을 텍스트 기반 모델에 전달하는 지식 증류 방법도 연구하고 있습니다.

  • 전파 그래프를 이용한 허위정보 탐지

지식 증류 (Knowledge Distillation)

  • 이미지 지식 증류를 통한 뉴스 추천
  • 멀티모달 생성 모델 연구

추천 시스템 (Recommender Systems)

  • 추천을 위한 의미 그래프 정제
  • 추천 시스템 모델 설계 컨설팅

참여연구원 (그래프 검색 및 시연 시스템 개발)

  • 제조 분야의 자연어 질문을 SQL로 변환할 때 필요한 테이블, 컬럼, 계산식, 업무 규칙을 검색하는 기능을 Python과 Neo4j로 개발했습니다. 테이블을 중심으로 검색 맥락을 구성하고 필수 업무 규칙이 빠지지 않도록 개선했습니다.
  • vLLM 기반 언어모델 서빙 환경을 구성하고 Streamlit으로 시연 화면을 만들었습니다. 그래프 검색과 모델 추론을 연결해 대화형 질의응답 테스트와 과제 시연을 지원했습니다.
  • Knowledge Graph
  • Multi-Turn QA

  • 개인화 추천 사례를 검토하고 사용자 표현, 질의 분석, 검색, 순위화의 단계별 평가 기준을 설계했습니다. 후보 검색의 포괄성과 추천 순위의 품질을 평가하고 사용자 이력이나 그래프 정보가 부족한 상황도 함께 살펴보도록 제안했습니다.
